# Code & Experiments

Hands-on code from the AAU CE2 AI course. This is the *doing* side of the repo;
the *studying* side lives in [`../exam_prep/`](../exam_prep/).

| Folder | What it is |
|--------|------------|
| `autoencoder/` | MNIST autoencoder experiment (script + notebook). Produces the plots in `autoencoder/outputs/`. Covers Module 9 (autoencoders/VAE). |
| `miniproject/` | Course mini-project: Rice image classification — CNN vs Vision Transformer, with/without pretraining. See its `README.md` for the full plan and code. |
| `class-exercises/` | In-class exercise notebooks and PDFs, one folder per module (`module1`–`module4`). Raw work as done in class. |
| `scratch/` | Throwaway/scratch notebooks (e.g. `testbook.ipynb`). Not exam material. |

Worked, written-up answers to the exercises are in `../exam_prep/Exercises_*.md`.
