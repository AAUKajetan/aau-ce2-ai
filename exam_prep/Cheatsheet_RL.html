Module 1 — MDP, Bellman, DP, MC, TD

MDP Tuple

(S, A, P, R, γ)
S: state space
A: action space
P(s'|s,a): transition prob
R(s,a): expected reward
γ ∈ [0,1): discount factor

Markov property: sₜ₊₁ ⊥ history | sₜ

Returns & Value Functions

Gₜ = Σₖ γᵏ rₜ₊ₖ Vπ(s) = Eπ[Gₜ | sₜ=s] Qπ(s,a) = Eπ[Gₜ | sₜ=s, aₜ=a] Vπ(s) = Σₐ π(a|s) Qπ(s,a)

γ→0: myopic · γ→1: far-sighted

Bellman Expectation

Evaluates a given policy π

Vπ(s) = Σₐ π(a|s) Σₛ' P(s'|s,a) [R(s,a) + γ Vπ(s')] Qπ(s,a) = Σₛ' P(s'|s,a) [R(s,a) + γ Σₐ' π(a'|s') Qπ(s',a')]

Bellman Optimality

Finds the best policy

V*(s) = maxₐ Σₛ' P(s'|s,a) [R(s,a) + γ V*(s')] Q*(s,a) = Σₛ' P(s'|s,a) [R(s,a) + γ maxₐ' Q*(s',a')] π*(s) = argmaxₐ Q*(s,a)

DP Methods (need model)

Policy Evaluation: apply Bellman expectation iteratively until Vπ converges

Policy Improvement: π'(s)=argmaxₐ Q(s,a)

Policy Iteration: alternate eval + improvement

Value Iteration: apply Bellman optimality directly

MC vs TD

MC: full episode, compute Gₜ

V(sₜ) ← V(sₜ) + α(Gₜ − V(sₜ))

Unbiased · high variance · episodic only

TD(0): one-step bootstrap

V(sₜ) ← V(sₜ) + α(rₜ+γV(sₜ₊₁)−V(sₜ))

Biased · low variance · online

SARSA vs Q-learning

SARSA (on-policy):

Q(s,a) ← Q(s,a) + α[r + γQ(s',a') − Q(s,a)]

a' sampled from ε-greedy → safer path

Q-learning (off-policy):

Q(s,a) ← Q(s,a) + α[r + γmaxₐ'Q(s',a') − Q(s,a)]

uses max → optimal but cliff-edge path
GLIE needed for convergence

n-Step & Exploration

Gₜ⁽ⁿ⁾ = rₜ+γrₜ₊₁+…+γⁿ⁻¹rₜ₊ₙ₋₁ + γⁿV(sₜ₊ₙ)

n=1: TD · n=∞: MC

ε-greedy: random w.p. ε, else argmax Q
GLIE: ε→0 as t→∞ (needed for convergence)

Module 2 — Deep Q-Networks (DQN)

DQN = Q-learning + NN + 2 tricks

Problem 1: Correlated samples
→ Experience Replay Buffer

Problem 2: Moving target
→ Target Network θ⁻

Deadly triad: function approx + bootstrap + off-policy → instability

DQN Target & Loss

yₜ = rₜ + (1−done)·γ·maxₐ' Qθ⁻(s',a') L(θ) = E[(yₜ − Qθ(sₜ,aₜ))²]

Gradient only through online net θ
yₜ is treated as a constant (stop gradient)

Huber loss: L1 for |δ|>1, L2 otherwise
Robust to large TD errors — preferred

Experience Replay

Circular buffer size N (e.g., 1M)
Store: (s, a, r, s', done)
Sample random mini-batches
→ Breaks temporal correlations
→ Enables data reuse

Warm up ≥1000 steps before training

Target Network θ⁻

Hard copy every C steps:
θ⁻ ← θ (every C steps)Parameters frozen between copies
→ Stabilizes the TD target

Without it: moving target → oscillation / divergence

ε-Greedy Decay

aₜ = argmaxₐ Qθ(s,a) w.p. 1−ε aₜ ~ Uniform(A) w.p. ε

Decay: 1.0 → 0.01 over 10⁵ steps
Evaluate always with ε=0

Hyperparameters & Ablations

ParamTypical Value
Replay buffer10⁵ – 10⁶
Batch size32 – 64
Target update1000 – 10000 steps
ε start/end1.0 / 0.01 over 10⁵ steps
Learning rate1e-4 – 2.5e-4
γ0.99
OptimizerAdam (default)

Ablation effects: No replay→correlated updates; No target→moving target divergence; Huber→MSE: sensitive to outliers; Adam→SGD: needs careful lr tuning

Module 3 — DDQN & Policy Gradients

Overestimation in DQN

Same network selects and evaluates the best action → systematically picks overestimated action → positive bias accumulates

Double DQN (DDQN)

Decouple selection and evaluation:

a* = argmaxₐ Qθ(s',a) ← online yₜ = rₜ + γ Qθ⁻(s', a*) ← target

Drop-in replacement for DQN
Same arch · change only 2 lines

Policy Gradient Theorem

Directly optimize πθ(a|s)

∇θJ(θ) = Eπ[∇θ log πθ(a|s) · Gₜ]

log πθ: direction to increase P(a|s)
Weighted by Gₜ: reinforce good actions

REINFORCE

Gₜ = Σₖ γᵏ rₜ₊ₖ (compute backward) θ ← θ + α ∇θ log πθ(aₜ|sₜ) · Gₜ

Unbiased · high variance
On-policy: fresh data per episode
In code: L = −Σ log_prob(aₜ) · Gₜ

Baseline & Advantage

∇θJ = E[∇θ log π(a|s)·(Gₜ−b(sₜ))] Aₜ = Gₜ − V(sₜ) ← MC form Aₜ = Qπ(s,a) − Vπ(s) ← general

Baseline doesn't bias gradient (cancels in expectation)
Natural choice: b(s)=V(s)
Aₜ>0 → increase π(a|s)
Aₜ<0 → decrease π(a|s)

Actor-Critic (one-step)

Actor πθ(a|s) — policy gradient
Critic Vφ(s) — TD baseline

yₜ = rₜ + γ(1−done)·Vφ(sₜ₊₁) δₜ = yₜ − Vφ(sₜ) ← advantage Actor loss: −log πθ(aₜ|sₜ) · δₜ Critic loss: (Vφ(sₜ) − yₜ)²

Online updates (no full episode)
Lower variance than REINFORCE

Algorithm Comparison

AlgoOn/OffSignalVar
DQNOffTD targetLow
DDQNOffTD (decoupled)Low
REINFORCEOnMC GₜHigh
Actor-CriticOnTD δₜMed

Value-based: discrete only, implicit policy
PG: discrete + continuous, explicit policy

Module 4 — DDPG & PPO (Continuous Control)

Why Continuous Control?

For aₜ ∈ ℝⁿ: argmax over Q is intractable

DDPG: deterministic actor, differentiate through it
PPO: stochastic actor, Gaussian distribution

DDPG: 4 Networks

NetParamsRole
Online actorθμθ(s)
Target actorθ⁻stable action
Online criticφQ(s,a)
Target criticφ⁻TD target

Both target nets needed — prevents actor-critic coupling

DDPG Updates

Soft target update (Polyak):

θ⁻ ← τθ + (1−τ)θ⁻ τ=0.005

Critic target:

yₜ = rₜ + γQφ⁻(s', μθ⁻(s')) (0 if done)

Actor (gradient ascent on Q):

∇θJ ≈ ∇ₐQφ(s,a)|_{a=μθ(s)} · ∇θμθ(s)

Exploration: aₜ = μθ(sₜ) + Nₜ
OU noise (correlated) or Gaussian

PPO Clipped Objective

rₜ(θ) = πθ(aₜ|sₜ) / πθ_old(aₜ|sₜ) L^CLIP = E[min(rₜÂₜ, clip(rₜ,1−ε,1+ε)Âₜ)] ε=0.2

Â>0: increase P(a|s), max (1+ε)×
Â<0: decrease P(a|s), min (1−ε)×

Full loss:

L = L^CLIP − c₁·L^VF + c₂·H[πθ]

c₁≈0.5 (value) · c₂≈0.01 (entropy)

GAE (Generalized Advantage)

δₜ = rₜ + γV(sₜ₊₁) − V(sₜ) ← TD residual Âₜ = Σₗ (γλ)ˡ δₜ₊ₗ

λ=0: TD(0), low var, high bias
λ=1: MC, high var, low bias
Typical: λ=0.95

Normalize advantages before update

Module 5 — Multi-Agent RL (MARL)

Stochastic Games

MDP extended to N agents:
(S, A₁,…,Aₙ, P, R₁,…,Rₙ, γ)

Joint action: a = (a₁,…,aₙ)
Transition: s' ~ P(·|s,a)
Partial obs → Dec-POMDP

SettingRewardsExample
CooperativeSharedMulti-robot
CompetitiveZero-sumChess, RTS
MixedIndividualAutonomous driving

Core Challenges

1. Non-Stationarity
Other agents change env → breaks convergence

2. Credit Assignment
Shared reward: who caused it?

3. Partial Observability
Agent i sees only oᵢ, not full s

4. Joint Action Explosion
|A₁|×…×|Aₙ| — exponential in N

CTDE Paradigm

Centralized Training:
Full state + all agents' obs/actions

Decentralized Execution:
Each agent uses only oᵢ

→ Rich credit assignment during training
→ Scalable at test time

VDN vs QMIX

VDN:

Q_tot = Σᵢ Qᵢ(oᵢ,aᵢ)

Additivity assumption (strong)

QMIX:

Q_tot = f_mix(Q₁,…,Qₙ; s)

Mixing net conditioned on global s
IGM condition (monotonicity):

∂Q_tot/∂Qᵢ ≥ 0 for all i

argmax Q_tot = individual argmaxes
→ Decentralized greedy execution

COMA: Counterfactual Advantage

Centralized critic estimates Q(s,a)
Credit assignment for agent i:

Aᵢ(s,a) = Q(s,a) − Σ_{a'ᵢ} πᵢ(a'ᵢ|oᵢ) Q(s,a₋ᵢ,a'ᵢ)

Marginalizes agent i's own actions
while holding all others fixed
→ Isolates i's contribution

MADDPG & MAPPO

MADDPG:
Centralized critic Qᵢ(s, a₁,…,aₙ)
Decentralized actor μᵢ(oᵢ)
Off-policy + replay buffer
Works: coop + competitive

MAPPO:
PPO + centralized critic (global state)
Decentralized actors (param sharing ok)
Strong coop baseline

Additional Techniques

Self-Play: train vs copies of self; risk: cyclic strategies

Parameter Sharing: all agents share weights; agent id as input; homogeneous agents only

Communication: DIAL, CommNet — differentiable, learns what to communicate

MARL Algorithm Summary

AlgoKey Property
IQLSimple; fails (non-stationarity)
VDNAdditive Q decomp
QMIXMonotonic mixing; IGM
COMACounterfactual advantage
MADDPGCts actions; central critic

IQL (Independent Learners): each agent runs its own RL (e.g., DQN) ignoring others. Simple but non-stationarity breaks convergence — no guarantees.
